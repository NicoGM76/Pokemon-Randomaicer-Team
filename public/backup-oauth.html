Pokémon Adventure Backup

Herramienta de mantenimiento de Pokémon Adventure Team Generator. Esta integración OAuth utiliza Google Drive únicamente como destino de copias de seguridad de la base PostgreSQL del proyecto. No es un servicio público de inicio de sesión para jugadores.

¿Para qué solicitamos autorización?

El propietario conecta una cuenta de Google dedicada a respaldos mediante rclone. La automatización de GitHub Actions está diseñada para crear un archivo PostgreSQL, cifrarlo con age, subir el archivo cifrado al Drive dedicado y comprobar su transferencia. También puede consultar los nombres y metadatos de archivos necesarios para esas tareas.

La autorización puede otorgar a rclone permisos sobre más archivos de Drive que los presentes en la carpeta de respaldos, dependiendo de los alcances OAuth aprobados. El uso previsto está limitado a la carpeta Pokemon-Adventure-DB-Backups.

Estado actual

La integración se está configurando. No se afirma que existan copias automáticas o restauraciones verificadas hasta completar las pruebas de operación.
