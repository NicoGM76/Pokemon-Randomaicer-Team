Política de privacidad

Esta política describe el uso de los datos de Google por Pokémon Adventure Backup, una integración privada que permite al propietario respaldar en Google Drive una base PostgreSQL asociada al generador de equipos Pokémon.

Datos que puede procesar la integración

  • Tokens de autorización OAuth necesarios para que rclone acceda a Google Drive.
  • Metadatos de archivos y carpetas de Drive, como identificadores, nombres y tamaño, cuando sean necesarios para guardar o verificar las copias.
  • Archivos de respaldo de la base PostgreSQL, cifrados localmente antes de cargarlos.
  • Datos técnicos de ejecución y resultados de las verificaciones del respaldo, sin incluir contraseñas en registros públicos.

Finalidad y límites del acceso

Usamos la autorización de Google Drive para guardar, listar y comprobar copias cifradas en la carpeta dedicada Pokemon-Adventure-DB-Backups. No utilizamos los datos de Google para anuncios, elaboración de perfiles ni venta de información. Dependiendo del alcance aprobado durante OAuth, Google puede conceder permisos más amplios que una sola carpeta; nuestro procedimiento está diseñado para trabajar exclusivamente en el destino configurado.

Almacenamiento, acceso y terceros

Los respaldos cifrados se almacenan en la cuenta de Google Drive dedicada que controla el propietario. La ejecución prevista utiliza GitHub Actions; sus credenciales de conexión OAuth y PostgreSQL se configuran mediante GitHub Actions Secrets, no se publican en el repositorio ni se distribuyen a usuarios del sitio. Google y GitHub actúan como plataformas técnicas necesarias para este proceso. No compartimos intencionalmente los archivos con terceros.

La clave privada de descifrado age se conserva fuera de GitHub Actions y no forma parte del acceso OAuth. Las copias son archivos cifrados, no bases de datos disponibles públicamente.

Retención y eliminación

Las copias pueden mantenerse como versiones históricas para permitir recuperación de errores. La automatización inicial no elimina versiones automáticamente; el propietario administra la retención y puede borrar respaldos y revocar accesos. Una vez revocada la autorización, la automatización deja de poder acceder a Drive mediante ese token, pero las copias guardadas permanecen hasta eliminarlas.

Revocar autorización o solicitar información

El propietario puede quitar el acceso desde la configuración de conexiones de su Cuenta de Google. Para solicitudes relativas a esta integración se puede utilizar el correo de asistencia mostrado en su pantalla de consentimiento OAuth. No publiques contraseñas ni tokens en incidencias de GitHub.

Estado de implementación

La integración se encuentra en configuración al publicarse esta política; no se declara todavía un respaldo automático operativo ni una restauración probada. Esta política se actualizará si cambian los permisos, los datos o los mecanismos de retención.
